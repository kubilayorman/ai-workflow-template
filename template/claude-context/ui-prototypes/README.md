# UI prototypes

A few screenshots or wireframes (usually 1–4) of how the app should look. They're blueprints, not exact designs: Claude follows them as closely as reasonable, and not every screen needs one.

- Put images directly in this folder, no subfolders. `.png`, `.jpg` and `.webp` work.
- Name each after the screen it shows, e.g. `login-page.png` or `dashboard.png`.
- For UI features, `/feature describe` and `/feature implement` look at them. A screen with a matching image follows it; together they set the overall look (colors, spacing, layout) of every other screen.
- The `/feature` actions never change these images. Add or replace one any time, and commit it like any other file.
